# Iteration Log

Use this section for dated development notes, tradeoffs, milestone work, and short historical snapshots that do not belong in a feature guide.

## Suggested Use

- Create one note per meaningful session or milestone when the history matters.
- Link out to the feature, system, logic, or troubleshooting notes touched by the work.
- Capture why a decision felt correct at the time, especially when alternatives were considered.
