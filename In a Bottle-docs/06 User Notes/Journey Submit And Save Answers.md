# Journey Submit And Save Answers

## What Changed

Journey now keeps the participant flow focused on the next useful action. The menu is for continuing, reviewing answers, jumping to a section, opening the character panel, reporting an issue in playtest builds, or submitting/saving answers.

## End Of Survey

- If answers are incomplete, `Review Answers` is highlighted first.
- If upload is available and the survey is complete, `Upload Answers` is highlighted.
- If upload is not available, `Save Answers` is highlighted instead.

## Saving A Copy

Local JSON and CSV copies are still available. Clipboard copy actions are secondary and live behind `More Copy Options` on the save screen.

## Upload Details

Before upload, Journey shows what will be sent, the configured destination, where uploaded answers will be visible, and whether identifying answers will be removed.
