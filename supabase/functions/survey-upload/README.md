# Survey Upload Edge Function

`POST /survey-upload` accepts the app's `SurveySubmissionBundle` JSON and stores allowlisted built-in survey responses in the private `survey_responses` table.

## Required Environment

- `SUPABASE_URL`
- `SUPABASE_SERVICE_ROLE_KEY`
- `SURVEY_UPLOAD_ALLOWLIST_JSON`
- `SURVEY_UPLOAD_ALLOWED_ORIGINS`

Example allowlist:

```json
{
  "surveys": [
    {
      "survey_id": "maplestory_pulse",
      "template_version": 2,
      "schema_hash": "c69e1f63dd9480f644261067dbbf8d4e46d4d6f390702e58ccba8b2748a74c37"
    }
  ]
}
```

The schema hash must match the `survey.schema_hash` generated by the Godot template loader for `Dev/SurveyTemplates/maplestory_pulse.json`. The current release-candidate hash is `c69e1f63dd9480f644261067dbbf8d4e46d4d6f390702e58ccba8b2748a74c37`.

Generate the identity from the Godot loader:

```powershell
& 'X:\Apps\Godot\Godot_v4.6.1-stable_win64.exe\Godot_v4.6.1-stable_win64_console.exe' --headless --path 'X:\Data\Projects\In a Bottle' --script 'res://Scripts/Tools/PrintSurveyIdentity.gd'
```

`SURVEY_UPLOAD_ALLOWED_ORIGINS` is a comma-separated list of exact hosted origins, for example:

```text
https://seasighed.github.io,https://surveys.example.com
```

Requests without an `Origin` header are still accepted for server-side smoke scripts. Browser requests from unlisted origins are rejected before storage.

Optional hardening:

- `SURVEY_UPLOAD_MAX_PER_INSTALL_PER_DAY`: default `5`; set `0` to disable the server-side per-install daily limit.

## Deploy

From the repo root after linking the Supabase project:

```powershell
supabase db push
supabase secrets set --env-file supabase/survey-upload.env
supabase functions deploy survey-upload
```

Keep `supabase/survey-upload.env` local-only. Commit only `supabase/survey-upload.env.example`.

## Local Validation

```powershell
deno test supabase/functions/survey-upload/validation.test.ts
```

## Live Smoke

After deploying the migration and function, run the live smoke script from the repo root:

```powershell
$env:SURVEY_UPLOAD_ENDPOINT='https://PROJECT_REF.supabase.co/functions/v1/survey-upload'
$env:MAPLESTORY_PULSE_SCHEMA_HASH='fill-from-PrintSurveyIdentity'
$env:SUPABASE_ANON_KEY='optional-if-required-by-your-function-gateway'
$env:SURVEY_UPLOAD_SMOKE_WRITE_OK='true'
deno run --allow-env --allow-net supabase/functions/survey-upload/smoke.ts
```

The smoke script creates private test rows for accepted and scrubbed uploads, then verifies duplicate, custom-survey, wrong-schema, and malformed-payload rejection paths.

## Storage Policy

Raw payloads are private intake records. Public sharing should be produced from manually reviewed aggregate exports or wrapped images, not direct table access.

Rejected uploads are tracked in the private `survey_upload_rejections` table with reason categories for rollout diagnostics.
